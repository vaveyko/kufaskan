# Kufar Scanner Bot

Telegram-бот для мониторинга новых объявлений об аренде квартир на [Kufar](https://re.kufar.by/).

Бот периодически проверяет выдачу по заданным URL, сохраняет уже просмотренные объявления и отправляет администраторам уведомления, когда появляются новые варианты.

## Возможности

- Мониторинг объявлений Kufar по заданным ссылкам.
- Асинхронные HTTP-запросы через `aiohttp`.
- Парсинг карточек объявлений с помощью `BeautifulSoup`.
- Уведомления в Telegram при появлении новых квартир.
- Поддержка нескольких администраторов.
- Защита от повторных уведомлений через локальную JSON-базу.
- Прогрев базы при первом запуске: старые объявления не рассылаются как новые.
- Хранение трёх последних найденных объявлений.
- Просмотр последних системных логов через Telegram-клавиатуру.
- Конфигурация секретов через `.env`.

## Как это работает

1. При первом запуске бот проходит по всем ссылкам из `KUFAR_URLS`.
2. Все найденные ID объявлений сохраняются в `data/seen_ads.json`.
3. Последние три объявления сохраняются в `data/recent_ads.json`.
4. После прогрева бот раз в 60 секунд проверяет первую ссылку из `KUFAR_URLS`.
5. Если объявление имеет новый ID, бот отправляет сообщение всем ID из `ADMIN_IDS`.
6. Повторно одно и то же объявление не отправляется.

## Структура проекта

```text
kufar_scanner/
├── main.py                  # Основной код Telegram-бота и парсера
├── .env                     # Секреты и настройки окружения, не коммитится
├── .env.example             # Шаблон переменных окружения
├── .gitignore               # Исключения Git
├── Dockerfile               # Сборка Docker-образа
├── docker-compose.yml       # Запуск через Docker Compose
├── pyproject.toml           # Зависимости и настройки проекта
├── uv.lock                  # Lock-файл зависимостей uv
├── .python-version          # Версия Python для uv/pyenv
└── data/
    ├── seen_ads.json        # База ID уже обработанных объявлений
    └── recent_ads.json      # Кэш последних трёх объявлений
```

Папка `data/` создаётся автоматически при запуске программы.

## Требования

- Python 3.10+.
- Telegram Bot Token.
- Telegram ID одного или нескольких администраторов.
- Зависимости из `pyproject.toml`.

Основные используемые библиотеки:

- `aiogram`
- `aiohttp`
- `beautifulsoup4`
- `lxml`
- `python-dotenv`

## Установка

### 1. Клонировать репозиторий

```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
cd kufar_scanner
```

### 2. Создать виртуальное окружение

Вариант с обычным `venv`:

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
```

Linux/macOS:

```bash
source .venv/bin/activate
```

### 3. Установить зависимости

Если используется `uv`:

```bash
uv sync
```

Либо через `pip`:

```bash
pip install aiogram aiohttp beautifulsoup4 lxml python-dotenv
```

## Настройка окружения

Создай рабочий файл `.env` на основе шаблона:

Windows PowerShell:

```powershell
Copy-Item .env.example .env
```

Windows CMD:

```cmd
copy .env.example .env
```

Linux/macOS:

```bash
cp .env.example .env
```

Заполни `.env` своими значениями:

```env
# Токен, выданный @BotFather
BOT_TOKEN=1234567890:YOUR_TELEGRAM_BOT_TOKEN

# Telegram ID администраторов через запятую
ADMIN_IDS=123456789,987654321
```

### Где получить значения

- `BOT_TOKEN`: создай бота через [@BotFather](https://t.me/BotFather).
- `ADMIN_IDS`: можно узнать через [@userinfobot](https://t.me/userinfobot) или аналогичного бота, который показывает числовой Telegram ID.

> Не публикуй `.env` в GitHub, GitLab или другом публичном репозитории. Настоящий `.env` должен быть указан в `.gitignore`.

## Настройка поиска Kufar

Ссылки, по которым идёт поиск, находятся в `main.py`:

```python
KUFAR_URLS = [
    "https://re.kufar.by/l/minsk/snyat/kvartiru?cur=USD&prc=r%3A0%2C420&rms=v.or%3A2%2C3%2C4%2C5",
    "https://re.kufar.by/l/minsk/snyat/kvartiru?cur=USD&page=1&prc=r%3A0%2C420&rms=v.or%3A2%2C3%2C4%2C5&size=30&cursor=...",
]
```

Чтобы изменить параметры поиска:

1. Открой Kufar в браузере.
2. Настрой город, тип аренды, стоимость, количество комнат и другие фильтры.
3. Скопируй URL из адресной строки.
4. Замени или добавь его в список `KUFAR_URLS`.
5. Первую ссылку используй как основную страницу выдачи: именно она проверяется в рабочем режиме каждую минуту.

## Запуск

Запусти бота из корня проекта:

```bash
python main.py
```

При успешном старте появятся логи примерно такого вида:

```text
[02.09 13:00:00] 🤖 Бот запущен и готов к работе.
[02.09 13:00:00] 🚀 Скрипт запущен. Загрузка базы...
[02.09 13:00:00] 🔥 Первый запуск: глубокий прогрев базы по 2 ссылкам...
[02.09 13:00:05] ✅ База успешно прогрета. Мониторинг запущен!
```

После запуска открой диалог со своим ботом в Telegram и отправь:

```text
/start
```

Если твой Telegram ID находится в `ADMIN_IDS`, появится клавиатура администратора.

## Команды и кнопки

| Действие | Назначение |
|---|---|
| `/start` | Проверяет доступ пользователя и открывает админ-панель |
| `📝 Последние 10 логов` | Показывает последние события работы бота |
| `🏠 Последние 3 квартир` | Отправляет три последних сохранённых объявления |

Доступ к кнопкам и уведомлениям имеют только пользователи, чьи Telegram ID указаны в `ADMIN_IDS`.

## Формат уведомления

При нахождении нового объявления бот отправляет сообщение в таком формате:

```text
🔥 Новая квартира!
💰 Цена: ...
📍 Адрес: ...
🕒 Опубликовано: ...

📝 Описание объявления...

🔗 Перейти к объявлению
```

## Хранение данных

| Файл | Назначение |
|---|---|
| `data/seen_ads.json` | Содержит ID уже обработанных объявлений. Нужен, чтобы не присылать дубли |
| `data/recent_ads.json` | Содержит последние три объявления для просмотра через кнопку бота |

Если нужно принудительно повторить прогрев базы, останови бота и удали файл:

```text
data/seen_ads.json
```

При следующем запуске бот снова обойдёт все URL из `KUFAR_URLS`, но старые объявления не будет отправлять в Telegram.

## Запуск в Docker

В проекте вроде настроены `Dockerfile` и `docker-compose.yml`, можно запустить контейнером:

```bash
docker compose up -d --build
```

Просмотр логов контейнера:

```bash
docker compose logs -f
```

Остановка:

```bash
docker compose down
```

Для обновления после изменений:

```bash
docker compose down
docker compose up -d --build
```

Убедись, что файл `.env` находится рядом с `docker-compose.yml`, если переменные окружения передаются контейнеру через Compose.

## Возможные проблемы

### Бот отвечает «У вас нет доступа»

Проверь, что:

- ты нажал `/start` со своего личного Telegram-аккаунта;
- твой числовой Telegram ID указан в `ADMIN_IDS`;
- после изменения `.env` бот был полностью перезапущен;
- ID записан без `@username`, только числом.

Пример:

```env
ADMIN_IDS=123456789
```

### Ошибка `Не найден BOT_TOKEN`

Проверь:

- `.env` лежит в одной директории с `main.py`;
- файл называется именно `.env`, а не `.env.txt`;
- в нём есть строка `BOT_TOKEN=...`;
- токен не пустой;
- пакет `python-dotenv` установлен.

### Бот не присылает старые объявления

Это ожидаемое поведение. При первом запуске выполняется прогрев: объявления сохраняются как уже просмотренные, но не рассылаются. Уведомления приходят только для вариантов, появившихся после завершения прогрева.

### Бот не находит объявления

Вёрстка Kufar может меняться, из-за чего CSS-классы или атрибуты карточек перестанут совпадать с селекторами в коде:

```python
soup.find_all(
    'a',
    attrs={"data-testid": re.compile(r'^kufar-realty-card')}
)
```

В таком случае нужно проверить актуальную HTML-разметку страницы и при необходимости обновить логику `fetch_ads_from_url()` и `parse_ad_element()`.
